# Distributed Home Lab — Ireland & Brazil

## Project Overview

This project is a hands-on IT infrastructure lab connecting two environments located in Ireland and Brazil.

The goal is to develop practical skills in networking, system administration, virtualization, remote access, troubleshooting and cybersecurity.

## Infrastructure

- **Location 1:** Ireland — Personal workstation and virtual machines
- **Location 2:** Brazil — Always-on laptop acting as a remote lab host
- **Remote Access:** Google Remote Desktop
- **Private Network:** Tailscale (planned)
- **Virtualization:** Oracle VirtualBox (planned)

## Project Objectives

- Build a private network connecting two geographically separated environments.
- Learn VPN and networking fundamentals.
- Deploy and manage Linux servers.
- Practice Windows administration.
- Learn virtualization and Docker.
- Develop troubleshooting skills.
- Document practical IT projects for a professional portfolio.
